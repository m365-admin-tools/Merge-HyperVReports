# Merge-HyperVReports
Combines several per-host HTML reports from [HyperV-Inventory.ps1](https://github.com/m365admintools/hyperv-inventory-report) into one self-contained file with a host tab bar across the top. Each host keeps its own dashboard and its own vInfo, vDisk, vNetwork, vSnapshot, vHost, vSwitch, vReplication, tabs, and they work independently.
